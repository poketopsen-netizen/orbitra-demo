# Orbitra V26 — DEMO deposit UX

- В окне пополнения сначала выбор криптовалюты (приоритет +10% DEMO) или банковского DEMO-способа.
- Отдельный экран реквизитов, название валюты, сеть, тестовый адрес, кнопка копирования.
- Исправлено позиционирование крестика.
- Банковский вариант всегда доступен в виде явно обозначенного образца, если администратор не настроил DEMO-банк для страны. После настройки /geo <страна> | bank | <название> | Банк: ...; IBAN: ... он заменится конфигурацией администратора.
- Все реквизиты учебные, никаких настоящих переводов. Бонус +10% начисляется только на виртуальный баланс после одобрения.
- Для надёжного хранения регистраций и настроек по-прежнему необходимо постоянное хранилище.
