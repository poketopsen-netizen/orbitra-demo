# Orbitra V38 — мобильный AI Bot DEMO

- После нажатия «Запустить автоматическую симуляцию» показывается 5 последовательных этапов: инициализация, учебный анализ рынка, подбор DEMO-пар, проверка стратегии, готовность.
- Этапы выполняются в интерфейсе и явно обозначены как демонстрация, а не фактический рыночный анализ.
- После подготовки вызывается существующий серверный API запуска.
- 7 виртуальных сделок завершаются через 5, 15, 30, 50, 70, 95 и 120 минут после запуска.
- Полная сессия: 2 часа. Остальные функции V37 сохранены.
- Важно: для уже начатых сессий новое расписание применяется относительно сохранённого времени запуска.
