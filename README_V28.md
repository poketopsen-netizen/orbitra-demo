# Orbitra V28 — единая DEMO-заявка

- Криптовалюта и банк всегда присутствуют в списке выбора (криптовалюта первой). Если способ не настроен для страны, пользователь видит запрос реквизитов, а не вымышленный адрес.
- При выборе банка пользователь вводит название банка-отправителя. Оно передаётся администратору Telegram вместе с заявкой.
- Кнопка активации AI Bot открывает ту же форму пополнения с минимальной суммой 50 DEMO USDT. Одобрение заявки активирует симуляцию и зачисляет DEMO-сумму в учебный кошелёк.
- Для криптовалютной DEMO-заявки применяется +10% виртуальный бонус.
- Реальные платежи не принимаются и не проверяются; никакие настоящие реквизиты не выдаются автоматически. Админ может настроить только учебные реквизиты командой /geo.
- SQLite в Render Free по-прежнему непостоянна; для хранения данных между развёртываниями потребуется отдельная постоянная БД.
